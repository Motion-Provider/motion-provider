You can start using Motion Provider in seconds. **No need for an external provider or client boundary wrappers**.
Choose your favorite package manager to start using Motion Provider which **supported by all major package managers**.

**For NPM:** 

```bash
npm i motion-provider 
```

**For Yarn:**

```bash
yarn add motion-provider
```

**For Pnpm:**

```bash
pnpm add motion-provider
```
