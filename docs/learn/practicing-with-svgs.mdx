Next, we're going to need the animation properties since we don't have any presets for this type of animation.    

<Callout type="tip" title="About the preset">
I actually decided to add it as a preset, so if you're reading this tutorial, rest assured that I have already added it to the preset registry. You can then call it `drawPath` in any MP component you wish, without having to define it manually.   
</Callout>


```ts
import { type AnimationModule } from "motion-provider";

const draw = {
  initial: {
    strokeDashoffset: "1",
  },
  animate: {
    strokeDashoffset: "0",
  },
} as const satisfies AnimationModule;

```

Full code reveal (only React): 

```tsx
import type { ComponentProps } from "react";

// shapeDefinitions is same

const SVGElements = {
  circle: "circle",
  line: "line",
  rect: "rect",
} as const;


const shapes = shapeDefinitions.map((shape) => ({
  ...shape,
  stroke: "var(--color-accent, #8b5cf6)",
}));

export default function PathDrawing() {
  return (
    <svg
      width={600}
      height={600}
      viewBox="0 0 600 600"
      className="size-60 max-w-full mt-12"
      role="img"
      aria-label="SVG shapes illustration"
    >
      {shapes.map(({ id, elementType, props, stroke }) => {
        const Component = SVGElements[elementType];

        return (
          <Component
            key={id}
            {...props}
            pathLength={1}
            stroke={stroke}
            style={{
              strokeWidth: 10,
              strokeLinecap: "round",
              strokeDasharray: "1 1",
              strokeDashoffset: 0,
              fill: "none",
            }}
          />
        );
      })}
    </svg>
  );
}
```

## Animating the shapes with MotionChain

Afterwards, we're going to utilize `<MotionChain />` to animate the shapes by simply wrapping the SVG elements with it.

<Callout type="danger" title="Crtical Point">
While doing so, to enable custom timing we should opt-in `animations` rather than `animation` prop because `animation`
allows you to set exactly 1:1 animation for each element you passed as children while `animations` allows you to set custom props arbitrarily.
</Callout>

```tsx
<MotionChain
  animations={shapes.map((_, i) => ({
    mode: draw,
    delay: i * 0.25, // setting custom delay for each item
    duration: 0.88,
    transition: "gentle",
  }))}
  config={{
    duration: 0.24,
    delayLogic: "sinusoidal",
  }}
  elementType="g"
>
  {shapes.map(({ id, elementType: Component, props }) => (
    <Component
      key={id}
      {...props}
      style={{
        strokeWidth: 10,
        strokeLinecap: "round",
        strokeDasharray: "1 1",
        fill: "none",
      }}
    />
  ))}
</MotionChain>
```
