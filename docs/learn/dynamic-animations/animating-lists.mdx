## Defining The Baseline

We're going to implement animations over items in the card and an easy to do that is reusing the component library that we already have in an app. 

<Callout title="Notice" type="note">
    Throughout the chapter, we're going to be **utilizing a well-known React component library called [HeroUI](https://heroui.com/)**. Since their APIs are almost identical, consider them interchangeable.      
</Callout>

```tsx
import { Description, Label, ListBox } from "@heroui/react";
import data from "./data"

export function List() {
  return (
    <div className="w-80 h-60 dark overflow-y-scroll my-8 scrollbar">
      <ListBox>
        {data.map((item) => (
          <ListBox.Item key={item.id} className="justify-between">
            <Label>
              {item.first_name}{" "}
              <span className="text-accent">{item.last_name}</span>
            </Label>
            <Description className="w-12 overflow-x-hidden truncate">
              {item.email}
            </Description>
          </ListBox.Item>
        ))}
      </ListBox>
    </div>
  );
}
```

## Animating The List Items

We will work on 2 type of animation in this tutorial, 

- Animating individually when the item has entered the viewport
- Animating items on scroll  

### Viewport Animation

It is good practice to work with `<MotionChain />` over `<MotionContainer />` per item as the chain applies given animation to each children element automatically while on the other hand container assigns the animation to the wrapped element. 

So we can simply wrap the mapped items using `MotionChain` for convenience — just like this,

<Registry slug="learn/animating-lists/2" title="Viewport-enter — Collectively (re-render)" />

```tsx
 <div className="w-84 h-60  overflow-y-scroll dark my-8 scrollbar">
    <MotionChain animation={{ mode: "fadeUp" }} controller={controller}>
      {data.map((item) => (
        <Card
          key={item.id}
          className="flex-row items-center justify-between bg-transparent hover:bg-accent/10"
        >
          <Label>
            {item.first_name}{" "}
            <span className="text-accent">{item.last_name}</span>
          </Label>
          <Description className="max-w-2xs truncate">
            {item.email}
          </Description>
        </Card>
      ))}
    </MotionChain>
</div>
```

All of the items appears with a smooth `fadeUp` animation but only for one time triggers solely when the component itself re-renders.

### Integrating In View Animations

Utilizing `configView` prop will enable the MP component to trigger items when they appear on the viewport but since the `MotionChain`
applies the animations to all items, one item's changes will reset the entire animation collectively so we should use `MotionContainer` for 
individual effects.   

<Registry slug="learn/animating-lists/3" title="Viewport-enter — Individually (scroll)" />

```tsx
<div className="w-84 h-60 overflow-y-scroll dark my-8 scrollbar">
  {data.map((item) => (
    <MotionContainer
      animation={{ mode: "fadeUp", duration: 0.36 }}
      controller={{
        configView: {
          once: false,
          amount: 0.12,
        },
      }}
      key={item.id}
    >
      {/* Card JSX */}
    </MotionContainer>
  ))}
</div>
```

### Parent-driven Scroll Animation

To implement the scroll-based animation, we can define the `scroll` inside `controller` and bound it to the container of items.

<Registry slug="learn/animating-lists/4" title="Scroll-driven (Scroll)" />

```tsx
"use client"

export default function ListBox() {
  const [scrollRoot, setScrollRoot] = useState<HTMLDivElement | null>(null);

  return (
    <div
      ref={setScrollRoot}
      className="w-84 h-60 overflow-y-scroll dark my-8 scrollbar"
    >
      {data.map((item) => (
        <MotionContainer
          key={item.id}
          animation={{ mode: "fadeUp", duration: 0.36 }}
          controller={{
            scroll: {
              source: scrollRoot,
              axis: "y",
              mode: "view",
              start: 0.1,
              end: 0.6,
            },
          }}
        >
          {/* Card JSX */}
        </MotionContainer>
      ))}
    </div>
  );
}
```

The scrollable parent element is captured using a callback ref and shared with every `MotionContainer` through the `scroll.source` option. 
Each card independently tracks its position within the parent's scroll viewport, synchronizing its animation progress with its visibility. 

Using `mode: "view"` ensures that animations are driven individually rather than by the container's overall scroll progress.

## Animating With Search On Keystrokes (advanced)

We talked about Motion Provider is not supporting layout animations or gestures with physics by design. 
However, this limitations are not a reason to build something dynamic. 

As a workaround, I dug around a bit to find something that could be replicated using built-in solutions.
The result is surprisingly solid.

Think about this, 


```tsx
import { Card, Description, Label } from "@heroui/react";
import { type AnimationResult, MotionContainer } from "motion-provider";
import { memo, useCallback, useEffect, useState } from "react";
import data from "./data";

type Contact = (typeof data)[number];

type ListItem = {
  item: Contact;
  isExiting: boolean;
};
const Item = memo(function Item({
  item,
  isExiting,
  onExited,
}: {
  item: Contact;
  isExiting: boolean;
  onExited: (id: Contact["id"]) => void;
}) {
  const handleMotionComplete = useCallback(
    ({ status }: AnimationResult) => {
      if (status === "finished" && isExiting) {
        onExited(item.id);
      }
    },
    [isExiting, item.id, onExited],
  );

  return (
    <MotionContainer
      animation={{
        mode: "fadeDown",
        duration: 0.48,
      }}
      controller={{
        trigger: !isExiting,
      }}
      onMotionComplete={handleMotionComplete}
    >
      <Card>
        <Label>
          {item.first_name}{" "}
          <span>{item.last_name}</span>
        </Label>
        <Description>{item.email}</Description>
      </Card>
    </MotionContainer>
  );
});
```

The most important detail is that now, we are tracking the animation state by listening the changes with the callback using `onMotionComplete`.

By doing so, we get informed about the animation accessing `finished` or `cancelled` props and conditionally calling another callback that will be called outside of this component. 

The rest are mostly covers React knowledge,

</Callout>

```tsx
export function List() {
  const [query, setQuery] = useState("");
  const [items, setItems] = useState<ListItem[]>(() =>
    data.map((item) => ({ item, isExiting: false })),
  );

  const debouncedQuery = useDebouncedValue(300, query);

  useEffect(() => {
    const term = debouncedQuery.trim().toLowerCase();

    setItems((prev) => {
      const previousItems = new Map(
        prev.map((entry) => [entry.item.id, entry]),
      );

      return data.flatMap((item) => {
        const matches = `${item.first_name} ${item.last_name} ${item.email}`
          .toLowerCase()
          .includes(term);

        const previous = previousItems.get(item.id);

        if (matches) {
          if (previous && !previous.isExiting) return [previous];
          return [{ item, isExiting: false }];
        }

        if (!previous) return [];
        if (previous.isExiting) return [previous];

        return [{ item: previous.item, isExiting: true }];
      });
    });
  }, [debouncedQuery]);

  const handleExited = useCallback((id: Contact["id"]) => {
    setItems((current) => current.filter((entry) => entry.item.id !== id));
  }, []);

  const hasVisibleItems = items.some((item) => !item.isExiting);

  return (
    <div className="dark my-4 flex w-84 flex-col gap-3 relative h-60 overflow-y-scroll">
      <SearchField
        aria-label="Search contacts"
        value={query}
        onChange={setQuery}
        onClear={() => setQuery("")}
        className="sticky top-0 z-50 w-full"
      >
        <SearchField.Group>
          <SearchField.SearchIcon />
          <SearchField.Input placeholder="Search by name or email..." />
          <SearchField.ClearButton />
        </SearchField.Group>
      </SearchField>

      <div className="flex flex-col gap-2 ">
         {items.map(({ item, isExiting }) => (
          <Item
            item={item}
            isExiting={isExiting}
            onExited={handleExited}
            key={item.id}
          />
        ))}

        {!hasVisibleItems && (
          <span className="py-4 mt-18 text-center absolute -translate-x-1/2 -translate-y-1/2 left-1/2 right-1/2 w-full">
            No matching contacts found.
          </span>
        )}
      </div>
    </div>
  );
}
```


Breaking down things,

| Responsibility | Implementation |
| --- | --- |
| Entry animation | Motion Provider |
| Exit animation | Motion Provider reverse |
| Rendering isolation | React memoization |
| Search updates | Debounced state |
