useReducedMotion reads the system preference and subscribes to changes while the component is mounted.

## Example

The status updates when the operating system or browser emulation changes its reduced-motion setting.

```tsx
"use client";

import { useReducedMotion } from "motion-provider";

export default function Demo() {
  const reduce = useReducedMotion();
  return <output>{reduce ? "Reduced motion requested" : "Standard motion"}</output>;
}
```
