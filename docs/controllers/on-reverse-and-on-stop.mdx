onReverse toggles direction according to the last controller command. onStop finishes the registered animations immediately.

## Example

Play the preview, toggle direction twice, then finish. After a reverse command, another onReverse calls play.

```tsx
"use client";

import { MotionContainer, useController } from "motion-provider";

export default function Demo() {
  const controls = useController();
  return (
    <section className="grid gap-3">
      <button type="button" onClick={() => controls.play()}>Play</button>
      <button type="button" onClick={() => controls.onReverse()}>Toggle direction</button>
      <button type="button" onClick={() => controls.onStop()}>Finish</button>
      <MotionContainer controller={controls} animation={{ mode: "slideUp", duration: 0.8 }}>
        Preview
      </MotionContainer>
    </section>
  );
}
```
