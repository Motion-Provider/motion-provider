createMotionConfig checks each entry against its selected motion component and preserves its literal key.

## Example

Declare the component type alongside its props. Spread the notice props onto MotionContainer and supply children at the render site.

```tsx
"use client";

import { MotionContainer, createMotionConfig } from "motion-provider";

const config = createMotionConfig({
  notice: { type: "MotionContainer", props: { animation: { mode: "fadeUp" } } },
});

export default function Demo() {
  const props = config.notice.props;
  return <MotionContainer {...props}>Notice</MotionContainer>;
}
```
